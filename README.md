# Mapping Tracer V8.2（终版）

一款面向投影描绘 / 图案映射场景的专业描图工具。基于 Web 技术构建，通过 Electron 打包为 Windows 桌面应用：**双击启动即默认全屏运行**，无需安装、无需浏览器。

![icon](mapping.png)

## 功能特性

### 01 工程文件（.mtrproj）
- 一键保存全部内容：参考图、图层、参考线与变形参数
- `Ctrl/⌘ + S` 快速保存，`Ctrl/⌘ + O` 打开工程
- 支持恢复最近一次自动保存，防止意外丢失编辑内容
- 自动保存数据通过 IndexedDB 本地持久化

### 02 参考图片
- 支持一次导入一张或多张参考图
- 支持直接将图片拖放到画布导入
- 参考图可整体变形，作为描图底稿

### 03 图层管理
- 树形图层堆叠，顶部图层优先显示
- 图层分组、拖拽排序、拖至顶层
- 锁定 / 隐藏 / 双击重命名 / 复制
- 独立不透明度调节，支持多选操作

### 04 绘图工具
- 选择（V）、钢笔（N）、多边形（P）、矩形（R）、椭圆（E）
- **钢笔拖绘贝兹**：单击添加尖角点；**按住拖动**直接拉出对称贝塞尔控制手柄，生成平滑曲线点
- **智能面板联动**：
  - 导入参考图 → 自动展开「参考图片」与「位置 · 缩放 · 旋转」精调面板
  - 选中节点 → 自动展开「节点编辑」面板
  - 选择钢笔 / 多边形 / 矩形 / 椭圆工具 → 自动展开「图形样式」面板

### 05 自由变换
- 旋转、斜切、透视、网格变形四种模式
- 网格控制点密度可选 3×3 至 6×6（9–36 点精调）
- `Ctrl+Shift` 拖拽可直接斜切；`Enter` 应用、`Esc` 取消
- 一键重置网格或重置参考图全部变形

### 06 节点编辑
- 尖角 / 平滑 / 非对称三种节点类型，右键快速切换
- **右键线段 → 新增点**：在路径任意位置插入节点（空白处右键插入到下一段中点）
- **右键节点 → 删除点**：快速移除多余节点，支持贝塞尔路径
- 拖动节点调整形状，方向键微调节点（按住 `Shift` 步进 ×10）
- **投影闪烁定位点**：选中节点高对比闪烁（频率 / 大小 / 颜色可调），方便投影对位描绘

### 07 图形样式
- 描边：颜色 + 0.5–80px 线宽
- 填充：颜色 + 透明度

### 08 参考线
- 横向 / 纵向参考线，画布拖动定位，右键删除
- 参考线仅作辅助显示，不会导出到 PNG

### 09 PNG 导出
四种导出模式：
| 模式 | 用途 |
|------|------|
| 原图合成 + 图形 | 所见即所得 |
| 透明底 + 白色填充 | 标准遮罩 |
| 黑底 + 白色填充 | 投影测试 |
| 透明底 + 白色描边 | 线稿 |

- 可选择是否包含可见参考图、是否按参考图原始像素比例导出
- 工具栏顶部的 **PNG 快速导出按钮**：使用当前导出设置一键出图

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `F11` | 切换全屏 / 还原窗口（启动默认全屏） |
| `Esc` | 逐级取消（菜单→变换→绘制→图像模式→节点→图形→工具栏）；**无可取消状态时退出程序** |
| `T` | 显示 / 隐藏工具栏 |
| `V` / `N` / `P` / `R` / `E` | 选择 / 钢笔 / 多边形 / 矩形 / 椭圆 |
| `Ctrl/⌘ + S` | 保存工程 |
| `Ctrl/⌘ + O` | 打开工程 |
| `Ctrl/⌘ + Z` | 撤销（`Shift` 反向为重做，或 `Ctrl/⌘ + Y`） |
| `Space` + 拖动 | 平移画布 |
| `I` | 图像模式切换 |
| `0` | 视图复位 |
| `Enter` / `Esc` | 应用变换 / 取消变换 |
| 方向键 | 节点微调（`Shift` ×10 步进） |

## 桌面版说明（Electron 打包）

- **便携单文件 exe**：`MappingTracer-V8.2.exe`，双击即用，无需安装运行时
- **默认全屏启动**，按 `F11` 可还原为窗口模式
- **按 `Esc` 退出程序**：Esc 优先用于逐级取消当前状态（取消绘制 / 退出变换 / 取消节点选择等），当没有可取消状态时才退出应用，浏览器中打开该页面则不受影响
- 应用图标：`mapping.png`（已转换为多尺寸 `icon.ico`）
- 工程与自动保存数据存放于 `%APPDATA%\Mapping Tracer`，更换电脑需手动迁移
- 导出 PNG / 保存工程时弹出系统「另存为」对话框


### 从源码构建

环境要求：Node.js ≥ 18、npm

```bash
# 安装依赖（国内网络建议先设置镜像）
# PowerShell:
#   $env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
npm install

# 开发预览（窗口模式可用 F11 全屏）
npm start

# 构建便携版 exe（输出至 dist/）
npm run dist
```

## 适用场景

- 投影仪辅助描图（Multiplexing/转印描稿）：黑底导出模式 + 节点闪烁定位
- 图片转矢量轮廓、图案映射与变形比对
- 教学演示：全屏沉浸式画布，无浏览器界面干扰
